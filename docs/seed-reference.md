## 절대 틀리면 안 되는 규칙
1. **1인 사업자 본인 식대/커피/간식 = 경비불인정** (소득세법§33①5 가사경비)
2. **카페 커피 = 소모품비가 아님**. 거래처 미팅이 아니면 경비불인정
3. **SW 구독료 = 지급수수료** (소모품비 아님)
4. **서점 구매 = 도서인쇄비** (소모품비 아님)
5. **교육 플랫폼 = 교육훈련비** (기타경비 아님)
6. **1인 사업자 = 복리후생비 해당 없음**
7. **100만원 이상 장비 = 감가상각비(자산등록) 강력권장**
8. **접대비 = 부가세 무조건 불공제**
9. **해외서비스(AWS, GitHub 등) = 부가세 매입세액공제 어려움**

## 한도 규칙
- 접대비: 연 1,200만원 기본 + 수입금액×0.3% (인적용역사업자)
- 접대비 적격증빙: 건당 3만원 초과 시 필수
- 경조사비: 건당 20만원 한도
- 차량유지비: 연 1,500만원 (감가상각 포함)
- 차량 감가상각비: 연 800만원
- 통신비: 사업용 비율만 (겸용 시 50~70%)
