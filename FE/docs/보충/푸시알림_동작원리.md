# 푸시 알림 배너 동작 원리

> 7iTAX 앱에서 결제가 발생하면 "AI 추천 세목" 알림이 뜨는 전체 과정을 설명합니다.

---

## 전체 흐름 한눈에 보기

```
[사용자가 카드 결제]
       ↓
[백엔드 서버가 결제 감지]
       ↓
[서버 → Firebase 서버로 푸시 요청]
       ↓
[Firebase → 사용자 폰으로 메시지 전달]
       ↓
[TaxFirebaseMessagingService가 메시지 수신]
       ↓
[NotificationHelper가 알림 배너 생성]
       ↓
[사용자 폰 상단에 알림 배너 표시]
       ↓
[사용자가 알림 탭]
       ↓
[MainActivity → 세목 확인 화면으로 이동]
```

---

## 1단계: Firebase 프로젝트 연결 (최초 1회)

Firebase는 구글이 만든 **푸시 알림 중계 서비스**입니다.
우리 서버가 직접 수만 대의 폰에 알림을 보내는 건 불가능하니까,
Firebase가 대신 전달해주는 구조입니다.

### 필요한 것
- Firebase Console(https://console.firebase.google.com)에서 프로젝트 생성
- Android 앱 등록 (패키지명: `com.ssafy.seveniTax`)
- `google-services.json` 파일 다운로드
- `app/google-services.json`에 넣기 (현재 임시 파일이 들어있음 → **실제 파일로 교체 필요**)

### 관련 파일
| 파일 | 역할 |
|------|------|
| `app/google-services.json` | Firebase가 "이 앱이 우리 프로젝트 것이다"를 인식하는 열쇠 |
| `build.gradle.kts` (top) | google-services 플러그인 등록 |
| `app/build.gradle.kts` | Firebase BOM + FCM 라이브러리 의존성 |
| `libs.versions.toml` | 라이브러리 버전 관리 |

## 2단계: 앱이 켜질 때 — 알림 채널 생성

Android 8.0(API 26)부터 알림을 보내려면 반드시 **알림 채널**을 먼저 만들어야 합니다.
채널 = "이런 종류의 알림을 보낼 거야"라고 OS에 등록하는 것.

```
앱 시작
  → SevenITaxApplication.onCreate()
    → NotificationHelper.createNotificationChannel()
      → "classification_channel" 이름으로 채널 등록
```

### 관련 파일
- `SevenITaxApplication.kt` — 앱 시작 시 `onCreate()`에서 채널 생성 호출
- `NotificationHelper.kt` — `createNotificationChannel()` 함수

```kotlin
// SevenITaxApplication.kt
override fun onCreate() {
    super.onCreate()
    NotificationHelper.createNotificationChannel(this)  // ← 여기서 채널 생성
}
```

## 3단계: FCM 토큰 발급 — "이 폰에 알림 보내줘"

앱이 처음 설치되면 Firebase가 이 폰만의 **고유 토큰**을 발급합니다.
이 토큰을 서버에 보내야 서버가 "이 사용자의 폰에 알림을 보내라"고 Firebase에 요청할 수 있습니다.

```
앱 설치/첫 실행
  → Firebase SDK가 자동으로 토큰 생성
  → TaxFirebaseMessagingService.onNewToken(token) 호출
  → (TODO) 서버 API로 토큰 전송
```

### 관련 파일
- `TaxFirebaseMessagingService.kt` — `onNewToken()` 함수

```kotlin
// TaxFirebaseMessagingService.kt
override fun onNewToken(token: String) {
    super.onNewToken(token)
    Log.d(TAG, "FCM Token: $token")
    // TODO: 서버에 토큰 전송 → 서버가 이 토큰으로 알림을 보냄
}
```

## 4단계: 서버가 알림 발송

사용자가 카드 결제를 하면, 백엔드 서버가 Firebase에 이런 데이터를 보냅니다:

```json
{
  "to": "사용자의_FCM_토큰",
  "data": {
    "type": "classification",
    "transactionId": "txn_123",
    "merchantName": "스타벅스 강남점",
    "amount": "5,500원",
    "aiCategory": "복리후생비",
    "confidence": "87"
  }
}
```

> 이 부분은 **백엔드 서버** 코드입니다. 프론트에서 하는 게 아닙니다.
> 프론트는 이 메시지를 **받기만** 합니다.

## 5단계: 앱이 메시지 수신

Firebase가 폰으로 메시지를 전달하면, 우리 앱의 `TaxFirebaseMessagingService`가 받습니다.

```
Firebase 서버 → 폰
  → TaxFirebaseMessagingService.onMessageReceived(message) 호출
  → message.data에서 type, merchantName, amount 등 꺼냄
  → type이 "classification"이면
    → NotificationHelper.showClassificationNotification() 호출
```

### 관련 파일
- `TaxFirebaseMessagingService.kt` — `onMessageReceived()` 함수

```kotlin
// TaxFirebaseMessagingService.kt
override fun onMessageReceived(message: RemoteMessage) {
    val data = message.data
    val type = data["type"]

    when (type) {
        "classification" -> handleClassificationNotification(data)  // ← 세목 분류 알림
        else -> handleDefaultNotification(message)
    }
}
```

## 6단계: 알림 배너 생성 및 표시

`NotificationHelper`가 실제로 알림 배너를 만듭니다.

### 알림 구조

```
┌─────────────────────────────────────┐
│ [7iTAX 아이콘]  7ITAX          지금  │  ← 앱 아이콘 + 이름 + 시간
│                                     │
│ 💳 결제가 확인되었어요                │  ← 제목 (굵은 글씨)
│ 스타벅스 강남점 · 5,500원            │  ← 가맹점 + 금액
│ AI 추천 세목: 복리후생비 (신뢰도 87%)  │  ← 보라색 텍스트
│ 탭하여 세목을 확인해주세요            │  ← 회색 안내 문구
└─────────────────────────────────────┘
```

### 배너가 만들어지는 과정

```
NotificationHelper.showClassificationNotification() 호출
  │
  ├── 1. PendingIntent 생성
  │     → 알림 탭 시 실행할 "예약 작업"
  │     → MainActivity를 열면서 navigate_to="classification_result" 전달
  │
  ├── 2. RemoteViews로 커스텀 레이아웃 적용
  │     → notification_classification.xml 레이아웃 사용
  │     → 가맹점, 금액, AI 추천 세목 텍스트를 동적으로 설정
  │
  └── 3. NotificationCompat.Builder로 알림 생성
        → 채널 ID, 아이콘, 제목, 내용, 커스텀 뷰 설정
        → manager.notify()로 OS에 알림 표시 요청
```

### 관련 파일
| 파일 | 역할 |
|------|------|
| `NotificationHelper.kt` | 알림을 만들고 OS에 표시 요청 |
| `res/layout/notification_classification.xml` | 알림 배너의 디자인 (XML 레이아웃) |

### 핵심 코드 설명

```kotlin
// NotificationHelper.kt

// 1. 알림 탭 시 실행할 작업 준비
val intent = Intent(context, MainActivity::class.java).apply {
    putExtra("navigate_to", "classification_result")  // ← 어디로 이동할지
    putExtra("transaction_id", transactionId)          // ← 어떤 거래인지
}
val pendingIntent = PendingIntent.getActivity(...)     // ← 나중에 실행할 수 있게 포장

// 2. 커스텀 레이아웃에 데이터 넣기
val expandedView = RemoteViews(context.packageName, R.layout.notification_classification)
expandedView.setTextViewText(R.id.notification_merchant, "스타벅스 강남점 · 5,500원")
expandedView.setTextViewText(R.id.notification_ai_category, "AI 추천 세목: 복리후생비 (신뢰도 87%)")

// 3. 알림 조립
val notification = NotificationCompat.Builder(context, CHANNEL_ID)
    .setSmallIcon(R.drawable.logo_symbol)           // 상태바에 보이는 작은 아이콘
    .setContentTitle("💳 결제가 확인되었어요")        // 축소 시 제목
    .setContentText("스타벅스 강남점 · 5,500원")     // 축소 시 내용
    .setCustomBigContentView(expandedView)           // 확장 시 커스텀 레이아웃
    .setContentIntent(pendingIntent)                 // 탭 시 실행할 작업
    .setAutoCancel(true)                             // 탭하면 알림 자동 삭제
    .build()

// 4. OS에 알림 표시 요청
manager.notify(id, notification)
```

## 7단계: 알림 탭 → 화면 이동

사용자가 알림을 탭하면 이런 일이 일어납니다:

```
[알림 탭]
  → PendingIntent 실행
  → MainActivity 열림 (또는 이미 열려있으면 재활용)
  → intent.getStringExtra("navigate_to") == "classification_result"
  → LaunchedEffect에서 navController.navigate(Route.ClassificationResult.path)
  → 세목 확인 화면(ClassificationResultScreen) 표시
```

### 관련 파일
- `MainActivity.kt`

```kotlin
// MainActivity.kt
val navigateTo = intent?.getStringExtra("navigate_to")

// ...
if (navigateTo == "classification_result") {
    LaunchedEffect(Unit) {
        navController.navigate(Route.ClassificationResult.path)
    }
}
```

## 자주 묻는 질문

### Q: 앱이 꺼져있어도 알림이 오나요?
네. FCM은 앱이 꺼져있어도 OS가 대신 메시지를 받아서 `onMessageReceived()`를 호출합니다.

### Q: google-services.json은 왜 필요한가요?
Firebase가 "이 앱이 우리 서비스에 등록된 앱이다"를 확인하는 인증서입니다.
Firebase Console에서 프로젝트를 만들고, 앱을 등록하면 다운로드할 수 있습니다.
현재 들어있는 파일은 **임시 파일**이라 실제 푸시는 동작하지 않습니다.

### Q: 알림 권한은 어떻게 받나요?
Android 13(API 33)부터는 `POST_NOTIFICATIONS` 런타임 권한을 사용자에게 요청해야 합니다.
`AndroidManifest.xml`에 권한은 선언되어 있고, 런타임 요청은 추후 구현이 필요합니다.

### Q: 서버에서는 어떻게 보내나요?
서버가 Firebase Admin SDK를 사용해서 아래 형태의 데이터를 Firebase에 전송합니다:
```json
{
  "to": "사용자의_FCM_토큰",
  "data": {
    "type": "classification",
    "transactionId": "txn_123",
    "merchantName": "스타벅스 강남점",
    "amount": "5,500원",
    "aiCategory": "복리후생비",
    "confidence": "87"
  }
}
```
이건 백엔드 팀이 구현하는 부분입니다.
